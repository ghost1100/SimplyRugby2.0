Simply Rugby – Full Stack Application

Technologies: C#, WPF, Visual Studio, SQLite
Project Type: HND Final Project
Scope: Local-hosted application for managing a rugby club

Simply Rugby was my HND final year project, designed and implemented as a full-stack desktop application to manage rugby club members, coaches, and their records. The project was intended to strengthen my coding skills while simulating a real-world software development environment.

Key Features

Dynamic user logins responding to different credentials (admin, secretary, coach, player)

CRUD operations for managing member skills, abilities, and personal details

Past records management: saved and displayed historical performance data (initially a bug that turned into a useful feature)

Mailing list generation: utilized StreamWriter to create output files based on admin/secretary selections

Database design: fully normalized SQLite database with structured tables for members, coaches, and performance records

Development Practices & Documentation

OOP & Coding Challenges: Initially lacked deep OOP knowledge, resulting in large classes (~20,000 lines) with many similar functions; overcame these challenges through extensive debugging and iteration

Design Documentation:

UML diagrams, cow-feet diagrams, and mock-ups

Reports and software engineering documentation covering project workflow

Code & File Management: Regex for input validation, Gitignore and gitattributes for project organization (before mastering GitHub)

Interface & Usability: WPF-based UI tailored for local club use, focusing on usability for non-technical staff

Outcome

This project earned a top grade (A) and represents a significant milestone in my software development journey, showcasing my ability to design, implement, and document a full-stack desktop application from scratch under tight deadlines.
